# JFM 2011 full-wall transverse-jet case plan

## Objective and evidence boundary

Target the full no-slip **case II** in Schlegel, Wee, Marzouk & Ghoniem,
*Journal of Fluid Mechanics* 676 (2011), 461–490, DOI
[10.1017/jfm.2011.59](https://doi.org/10.1017/jfm.2011.59).

Matching the nondimensional inputs is necessary but does not by itself reproduce
the published vortex-method calculation. The present solver uses a Cartesian MAC
grid, a staircase pipe, a parabolic pipe inlet, and finite free-slip outer boundaries.
Results must therefore be called a **published-parameter target case** until the
boundary conditions, nozzle profile, spatial convergence, and stationarity gates
below have passed.

## Published anchors

| Quantity | Target |
|---|---:|
| Jet-to-crossflow ratio, `r` | 5 |
| Crossflow Reynolds number, `Re_inf` | 245 |
| Jet Reynolds number, `Re_j` | 1225 |
| Nondimensional viscosity, `nu/(U_inf D)` | `1/245 = 0.00408163265` |
| Incoming wall-layer thickness at nozzle, `delta/D` | 0.5 |
| Published interpolation spacing | 0.035 D |
| Published final time | `t U_inf/D = 12` |
| Published mean-flow window | `10 <= t U_inf/D <= 11.5` |

The paper reports that the case-II trajectory was stationary by `t=12`. It uses
instantaneous vorticity-magnitude isosurfaces at `t=12` and time-averaged fields
over `10 <= t <= 11.5`. Its full-wall analysis distinguishes a nozzle-edge strand
from a second wall-vorticity strand initiated downstream in the lee-side
recirculation region.

## Gate 0 — numerical method readiness

The original 8-cells/D pilot at the target Reynolds number was deliberately stopped:
the maximum speed grew from 14.79 at `t=0.85` to 90.94 at `t=0.90`, although the
projected divergence remained below `8e-12`. This is a convective instability of
the current centered, non-energy-conserving momentum discretization.

**Gate status: passed for the 8-cells/D stability pilot.** The skew-symmetric run
completed `t=1` in 491 steps. At `t=0.90`, maximum speed was 11.63 rather than
90.94; at `t=1`, maximum speed was 10.84, kinetic energy was 378.50, and divergence
was `3.55e-12`. The rapid-growth guard was active with a 0.1 time-unit window,
maximum-velocity factor 3.0, and face-energy factor 1.5. This verifies bounded
coarse-grid execution, not vortex resolution.

Implemented readiness controls:

1. Added a skew-symmetric kinetic-energy-controlled MAC advection option and
   retained the centered operator as a regression reference.
2. Added discrete-work, convergence and guard-rejection tests, plus a rolling
   failure guard that aborts on rapid speed or energy growth.
3. Repeated and passed the 8-cells/D `t=1` pilot with bounded maximum speed and
   kinetic energy, accepted divergence and scalar conservation, and no timestep
   collapse.

No artificial velocity clipping is permitted.

## Gate 1 — boundary and inlet fidelity

1. Treat `delta/D=0.5` as the boundary-layer thickness **at the nozzle**, not as
   the inlet parameter. Measure the undisturbed profile immediately upstream and
   calibrate the inlet profile or use a precursor until nozzle-plane `delta99/D`
   is 0.50 within 2%.
2. Quantify the exit profile generated by the current 2D-long parabolic pipe. The
   paper assumes a very thin jet boundary layer represented by an azimuthal vortex
   sheet; the present profile is not equivalent. Add a selectable nozzle/pipe
   profile and carry both profiles as a sensitivity if an exact mapping is not
   possible.
3. Retain the full no-slip plate for the primary run. A free-slip/suppressed-wall
   run may be used as a mechanism ablation, but it is not identical to the paper's
   reduced vorticity-influx case I and must be labelled accordingly.

## Gate 2 — domain and resolution pilots

Use the paper-informed domain target `-3 <= x/D <= 10`, `0 <= y/D <= 8`, and
`-5 <= z/D <= 5`, with a 2D pipe below the plate. The larger height provides room
for the `r=5` trajectory; the spanwise extent matches the published wall treatment.

Run in stages:

| Stage | Grid | End time | Purpose |
|---|---:|---:|---|
| Stability | 8 cells/D | 1 | Operator and failure-guard verification only |
| Development | 16 cells/D | 3 | Boundary proximity, exit profile, separation topology |
| Primary | 20 cells/D | 14 | Long-time development plus post-`t=12` confirmation |
| Sensitivity | 16 and 24–28 cells/D | selected windows | Resolution and domain sensitivity |

The published spacing of 0.035D corresponds to about 28.6 samples/D, but the
different numerical method prevents treating that number as automatic equivalence.
The current replicated-field MPI implementation may become memory-limited near
that resolution; measure peak resident memory during the 16- and 20-cells/D pilots
before allocating the finest run.

## Gate 3 — trajectory stationarity

The current scalar centroid at one `x` station is insufficient. Implement the
published observable: a jet-centre streamline integrated through block-averaged
velocity, initialized at the nozzle centre. Keep scalar-centroid trajectories as a
supplementary diagnostic.

Save independent block means for `[8,10]`, `[10,11.5]`, and `[11.5,13]`. On their
common resolved trajectory segment, require two successive comparisons to satisfy:

- relative L2 change in trajectory height below 2%;
- maximum pointwise height change below 0.05D;
- no systematic drift in penetration height;
- block changes below 5% in recirculation volume and wall-normal circulation.

If these tests fail at `t=13`, continue in restartable 2-time-unit blocks. A single
instantaneous trajectory that looks smooth is not evidence of stationarity.

## Gate 4 — vortex-source diagnostics

Reproduce the paper-facing views before adding generic Q plots:

1. At `t=12`, plot `|omega|=17.5` isosurfaces coloured by signed wall-normal
   vorticity `omega_y`, from windward and lee-side views.
2. Plot the same quantity from the `[10,11.5]` mean field.
3. Plot mean `omega_y` on `y/D = 0.4, 1.0, 1.6` planes. Identify connected strands
   seeded from:
   - **A, jet/nozzle family:** the nozzle-edge region `-0.5 <= x/D <= 0.5`;
   - **B, separated-wall family:** the downstream lee-side recirculation region.
4. Plot near-wall streamlines at `y/D = 0.2` and `0.4`, the `u_x=0`
   recirculation boundary, wall-shear separation lines, and
   `Gamma(y)=integral_(z>0) omega_y dz dx`.
5. Advect two passive marker families—one released from the nozzle annulus and one
   from the lee-side wall/separation region—to visualize material origin.

Marker origin, scalar concentration, and connected-component seeding support a
source interpretation but do not prove vorticity provenance after diffusion and
merger. The strongest attribution test is the paired full-wall versus
separation-suppressed ablation, reported as a model comparison rather than an exact
reproduction of case I.

## Proposed primary run controls

- `r=5`, `Re_j=1225`, calibrated nozzle `delta/D=0.5`, `Sc=1` marker scalar.
- Start with `CFL=0.30`, `dt_max=0.01`; relax only after the stability gate.
- Integrate to `t=14`, with restart checkpoints at least every `0.5` time unit.
- Sample scalar diagnostics every `0.05`; save full 3-D fields every `0.5` through
  `t=8` and every `0.25` during the averaging/stationarity interval.
- Use PETSc CG+GAMG with four ranks initially, but select rank count from measured
  wall time and peak memory on the expanded grid.
- Preserve all failed manifests and record the first instability indicator; never
  overwrite a failed or completed output directory.

## Completion criterion

Call the result a JFM-parameter **comparison** only after numerical stability,
nozzle-layer calibration, outer-boundary checks, trajectory stationarity, and at
least one resolution sensitivity have passed. Call it a **reproduction** only if
the jet-exit and wall-vorticity boundary conditions are shown to be equivalent to
the published case within stated tolerances.
